# 🛡️ Blockchain-Based Fake Product Identification System

A web-based application developed to detect and prevent fake products using blockchain concepts.  
This system allows manufacturers to register products and customers to verify product authenticity using unique QR codes.

---

## 🚀 Features

- ✅ Product Registration by Admin
- ✅ Unique QR Code Generation
- ✅ Product Verification by Customers
- ✅ Fake Product Detection
- ✅ Blockchain-based Data Integrity Concept
- ✅ Secure Backend using Spring Boot

---

## 🛠️ Technologies Used

- Java
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript
- Maven

---

## 🏗️ System Architecture

1. Admin registers product details.
2. System generates unique QR code.
3. Customer scans QR code.
4. Product authenticity is verified from database/blockchain.
